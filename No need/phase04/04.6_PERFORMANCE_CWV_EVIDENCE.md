# Phase 04.6 — Performance and Core Web Vitals

CI measures 20 sequential loopback SSR requests to home/projects and caps raw response bytes. This guards against accidental catastrophic local performance regression; it is **not a load test or field Core Web Vitals**. No claim is made about 75th percentile LCP/INP/CLS on real users.

External acceptance protocol: deploy representative approved content, media, tag/list sizes, caching mode, bandwidth and realistic concurrency. Test mobile 4G/low-tier device + desktop, browser cold cache/warm cache, CDN hit/miss, 1/5/20 concurrent visitors, user editing while reading. Record TTFB, error rate, HTTP p95/p99, server CPU/memory/pool pressure, Web Vitals (LCP <=2.5s, INP <=200ms, CLS <=0.1 at p75) as aspirational pass thresholds, time-series window, costs and raw evidence. Check no draft leakage and cache purge on unpublish under load. Obtain owner accepted performance budget and repeat after content/design changes.

Until these real measurements exist, **P4-059 is NOT fully accepted.**
