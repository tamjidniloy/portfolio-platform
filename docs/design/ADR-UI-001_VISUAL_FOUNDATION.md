# ADR-UI-001 — Approved Visual Foundation

**Status:** APPROVED (owner decision in conversation)
**Decision date:** 2026-10-23
**Scope:** Phase 02 visual identity, not approval of all future screen designs.

## Decision
- Public site design direction: Minimal Editorial + Engineering Case Studies (hybrid).
- Primary visual theme: dark-first.
- Core palette direction: dark navy, restrained muted teal and blue accents.
- Layout language: editorial hierarchy, spacious reading areas, structured technical case-study cards.
- Typography direction: clean professional sans-serif headings/body, occasional monospace technical labels.
- Design tool: Penpot.
- Reuse policy: prefer suitable maintained npm UI packages, not redundant custom basic controls.
- Avoid fake metrics, false publication claims, decorative overload and large blocking animations.

## Open / not approved
- Final public-facing brand/name: TBD.
- Exact font family: TBD (candidate families may be compared).
- Pixel-level color values and contrast pairs: subject to testing.
- Light-mode toggle as Release 1 feature: TBD.
- Final navigation, CTA copy, design tokens, individual screen wireframes: further review.

## Evidence and dependency

## Change control
Changes to this approved foundation require an explicit owner decision and an update to this ADR.
