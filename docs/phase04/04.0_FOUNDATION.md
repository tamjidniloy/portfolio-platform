## Local development

Requires Node.js 22 (see `.nvmrc`), npm and Docker Compose.

```bash
cp .env.example .env
docker compose up -d postgres
npm ci
npm run dev
# Browse http://127.0.0.1:3000/
# HTTP GET /healthz and /readyz
npm run check
```

`npm run dev` reads `.env` if present. In production use `npm run build && npm run start` with separately managed production environment variables. No deployment has been configured. `/healthz` is live without PostgreSQL; `/readyz` returns HTTP 503 unless PostgreSQL answers `SELECT 1`. Neither endpoint exposes a connection string, driver exception, or credentials. Local Compose password is **development-only**.
