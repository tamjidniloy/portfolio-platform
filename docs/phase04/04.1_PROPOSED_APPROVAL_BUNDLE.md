These values are *only candidates* and require review of privacy notices, legal basis, deletion enforcement, ongoing revisions and provider options. Avoid implementing automatic deletion on assumptions.
6. **Migrations:** Once approved, use a maintained migration library or explicitly adopt reviewed immutable SQL under a separately privileged migration account, numbered versions, SHA-256 ledger and staging rollback/restore evidence. Only candidate test runner is presently implemented. Never connect unapproved SQL to `DATABASE_URL`.
